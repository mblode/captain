Captain is one chat that runs your coding agents. You tell it what you want, or hand it a ticket. It keeps a task list, starts a full harness (Claude Code, Codex or Cursor) on each task in its own git worktree and [cmux](https://cmux.com/) workspace, and comes back to you only with decisions: plans to approve, questions to answer, PRs to merge.

The chat is a Claude Code session running the `/captain` skill. Everything it does goes through the `captain` CLI, and every task is a plain markdown file, so you can read, edit or drive any of it by hand.

## Requirements

- Node.js >= 24
- `git`, `gh` ([GitHub CLI](https://cli.github.com/)), `claude` ([Claude Code](https://claude.com/claude-code)) and [`cmux`](https://cmux.com/) on your PATH
- Optional harnesses: `codex` and `cursor-agent`
- Optional: `LINEAR_API_KEY` or `DONEBEAR_TOKEN`, to add tasks from tickets

## Install

```bash
npm i -g cmux-captain   # the CLI
captain install         # add the skills, then check your setup
```

`captain install` adds the `/captain` skill plus the pipeline skills each worker's brief runs (`/tidy`, `/pr-creator`, `/pr-babysitter`), then checks node, git, gh, claude, codex, cursor-agent, cmux and `LINEAR_API_KEY`. Re-run it any time.

Then create a project and start the chat:

```bash
captain init rebuild --repo ~/code/app --wip 4
```

Open Claude Code in its own cmux workspace and run `/captain`. See [Usage](/usage) for how a task gets from a message to a merged PR.
